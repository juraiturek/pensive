# Six Thinking Hats migration

## Approved scope

One shared tool is available on SWOT/TOWS, PAGES, VPC and 5 Whys. Use the same picker, copy-to-skill handoff and reflection format. Support full-canvas and explicit item or causal-node targets. Pilot application guidance on SWOT/TOWS and 5 Whys. PAGES and VPC use the common method with their own framing and content.

## Execution sequence

1. Establish a test for the common action and append-only response. Integrate request checks and a typed thought with each state module, schema and packager.
2. Add the shared browser picker and thought card. Verify clipboard handoff, JSON import/export and HTML save/reopen on all four canvases.
3. Extract the common stances and add the approved framework extensions. Review six distinct outputs, an opposing Yellow/Black pair, a no-suggestions case and a causal-node case with wider context.
4. Run the skill validator and executable regressions. Record source provenance and verification limits.

The existing framework packagers remain the normal result entry points. Existing proposals must be resolved first. A result appends one structured thought with a stable target reference and captured label. Suggestions are optional prose. Existing HTML can be updated by packaging its complete exported state with the current script.
