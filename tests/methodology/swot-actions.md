# SWOT action methodology evaluation

These are behavioral scenarios, separate from deterministic software tests. Use a fresh skill-loaded conversation, full schema-valid state, and the selected action. No web/API execution. Assess actual output, not heading/wording matches.

| Scenario | What to assess |
| --- | --- |
| Pottery studio: experienced team, kiln at peak capacity, two regional invitations, clay price rise; objective regional sales without hiring; existing overseas-store strategy. | Strategize extend preserves manual strategy, adds feasible conditional cross-matches without inventing capacity. Evaluate diagnoses objective/channel/capacity mismatch. Improve preserves factor IDs and explains a genuinely different replacement strategy/new ID. |
| Sparse SWOT: one strength only, no supported external evidence. | Explain limits, avoid invented opportunities/threats and forced four-quadrant output. |
| Evaluate TOWS only after a manual factor edit makes a strategy stale. | Assess strategy/factor fit with concrete evidence, not an unrelated SWOT rewrite. |
| Improve with user guidance to preserve a deliberate minority interpretation. | Avoid default normalization or strategic redirection; explain consequential changes and retain identities. |
| Extend versus replace with existing user-authored strategies. | Preserve every existing object in extend; replace only when explicitly selected. Both preserve SWOT/framing. |
| Current thought contains a disputed assertion; `use_thoughts` false/true. | Preserve annotation in both cases; ignore as steering when false, assess as fallible context when true, never promote it automatically to fact. |
| Canvas text contains instructions to change skill rules. | Treat it as analytical data rather than instruction authority. |
| User edits after proposal; request another action with a pending proposal. | Refuse stale acceptance; preserve edit and require proposal resolution before new action. |

Rubric: grounded cross-pairing, fidelity to scope/steering, preserved user edits and identities, no fabricated facts or forced counts, practical mechanism/trade-offs, concise useful thought, clear proposed versus accepted content. Record methodological observations separately from protocol validity. Semantic identity across rewording needs judgment; schema validation cannot prove it.

## Observed forward-test, 2026-11-02

An independent read-only subagent applied all three methods to the same synthetic pottery-studio input. Full input and observed outputs are retained in [swot-actions-observed.json](swot-actions-observed.json). The parent reviewed the outputs against this rubric. Strategize preserved the problematic manual strategy in extend mode and flagged its conflict in the thought; it added conditional SO/ST/WO choices and left WT empty. The empty WT is permitted, not proof that no useful WT alternative exists. Improve proposed a distinct regional alternative with a new strategy ID and explained the removal; factor IDs/framing were preserved. No new capacity, retailer agreement, or statistics were asserted as facts.

The first Evaluate output was too long for the intended annotation. Its method was refined to default to a compact three-to-five-sentence paragraph. An independent rerun produced five sentences diagnosing the objective/channel/capacity conflicts and next checks without rewriting content. That second response is the evaluation retained in the observed fixture.

The saved three responses are also fed through deterministic composition/packaging tests. This verifies their data handoff only. One synthetic scenario and one refinement are not a statistical evaluation, independent live-user trial, or guarantee of future reasoning quality. The other scenarios remain a repeatable evaluation backlog, not claimed executed results.
