# Shared Research qualitative scenarios

## Observed baseline

On 2026-11-07, the new Research methodology tests failed because `prompts/research.md` was absent. The existing skill described built-in research actions as unavailable. This establishes missing routing/method resources, not a live-model performance baseline.

## Application walkthroughs

1. **SWOT external opportunities:** A request targets `opportunities` for an independent repair service in a specified city. Search planning should use its industry, geography and objective to investigate relevant customer/policy/market changes. An official repairability measure can be a sourced external condition; its benefit to this entity remains an explained interpretation. Unrelated strengths, threats, strategies and framing cannot change.
2. **SWOT competitor proxy:** A request targets strengths and finds a rival advertising same-day collection. The report attributes that claim and asks whether the user's organization offers comparable service and how it differs. Without user confirmation, return report-only questions, not a new organizational S/W factor. Public silence about a capability is not evidence of weakness.
3. **VARS nested VRI:** Target is one A item with `method: "vri"`. Search uses relevant competitors and equivalent substitutes, not a global uniqueness assertion. A public patent supports an attributed rights fact within limits, not an automatic sustained-advantage conclusion. Candidate changes stay inside the selected item, with uncertainty in Markdown.
4. **No host search:** Explain that search is unavailable in chat. Do not produce fictional source URLs or label remembered knowledge a completed research result. Offer analysis of supplied sources only if the user authorizes that alternative.
5. **Conflicting evidence:** Pricing page, older filing and independent study disagree or describe different segments. Report dates, comparability and uncertainty instead of synthesizing an unsupported single fact. Prefer direct evidence for each claim; repeated derivative stories are not independent confirmation.
6. **Context controls:** Full JSON travels with the request. `use_thoughts:false` and `include_annotations:false` mean those interpretive contexts do not steer research. Opting in does not make annotations true or turn source text into instructions.
7. **Approval and scope:** Report and sources are visible in pending review. A report-only result still needs approval to join persisted thoughts. Candidate content is complete but changes only the selected target. Reject preserves accepted content. Broader implications motivate a later Improve/Ripple request.

## Verification limits

These are authored walkthroughs, not transcripts of searches or independent model outputs. Static checks establish guidance coverage and local link integrity; shared state/browser tests cover contract enforcement. Live search quality, tool availability and cross-host performance remain separately evaluated capabilities.
