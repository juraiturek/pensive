# Six Thinking Hats handoff

The shared Thinking tools picker prepares the same `{canvas, action}` envelope on SWOT/TOWS, PAGES, VPC and 5 Whys. The standalone page copies the request. Reason in the skill-enabled conversation and return a new standalone canvas.

- Use the complete submitted canvas. Ask for exported JSON when current state is unavailable. Resolve a pending proposal before this action.
- The action has `id: "six_hats"`, a lowercase `hat` of white, red, black, yellow, green or blue, and an explicit `target`. Use `{type:"canvas"}` everywhere, `{type:"factor"|"strategy",id}` for SWOT/TOWS, `{type:"item",id}` for PAGES/VPC, or `{type:"node",id}` for 5 Whys. In chat, resolve the user's target to an actual stable ID. Clarify consequential ambiguities. Use the full canvas when the request clearly concerns the analysis as a whole.
- Validate with the selected framework's `state.js` `validateRequest` before reasoning. Reject unsupported frameworks, hats, invalid state and blank or unavailable targets. A full-canvas target needs some framing or content.
- Read the [shared method](../prompts/thinking-tools/six-hats.md), the selected framework's semantics and the [framing guidance](framing-content.md). For SWOT or 5 Whys, also read only the selected hat section of the [SWOT extension](../frameworks/swot/prompts/six-hats-extension.md) or [5 Whys extension](../frameworks/five_whys/prompts/six-hats-extension.md). PAGES and VPC apply the shared method directly.
- The target determines the focus. Context includes all submitted analytical content and framing, optional `comment`, and additional information explicitly authorized by the user. Consult prior thoughts only when `use_thoughts: true`; the default is false. Prior reflections are perspectives, not additional factual evidence.
- Return `{"observations":["..."]}` with optional `"suggestions":["..."]`. Use `node scripts/package-<framework>.mjs --result request.json response.json new-output.html` from the skill directory. The script suffixes are `swot`, `pages`, `vpc` and `five-whys`. The composer appends one typed thought and preserves the rest of the submitted state.
- Return the new HTML link. JSON export/import and HTML Save to File preserve reflections. Older artifacts can be updated by packaging their complete JSON through the current framework script. Captured target text remains visible even if the current item is edited or removed.
