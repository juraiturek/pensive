# Create Five Forces

Read the [workflow](../../../references/five-forces-workflow.md), [methodology](../methodology.md), all five selected force guides and shared [framing fit](../../../references/framing-content.md).

Explicit blank creation needs no analytical prerequisite: copy the established empty canvas to a new destination. For contextual creation, first extract boundary, geography, strategic objective and an initial participant map. Clarify essential gaps before substantive analysis. Explicit unknown participant groups are valid; do not require exhaustive participants or invent them. A recognizable industry name alone may still be too broad for the question.

Generate a disclosed preliminary draft using supported context, not facts from presumed research. Unsupported assessments remain null and analysis may be sparse. Populate stable analysis snippets, causal reasoning and evidence qualifications, with supporting material in research_notes. Distinguish observations, mechanisms and implications; assess confidence from coverage and evidence quality. Current claims and projected changes must remain separate. Do not silently revise the framing to accommodate out-of-bound findings. Check internal consistency and external framing/economic fit. Initialize complete state without a pending proposal, package and explain uncertainties.
