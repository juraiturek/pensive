# Formulate or review Takeaways

Relate the proposed takeaway to what the user sought to understand. Trace each material conclusion to specific findings in the current analytical core and test whether it still fits the framing. Look for contradictions, tradeoffs and assumptions that affect what the user can carry forward. Keep uncertain claims conditional. If the canvas does not support a firm result, offer a specific open question, observation or next investigation that would change the conclusion. Keep the body concise and useful as editable standalone text.

For **Formulate**, synthesize what follows from the analysis. Separate options and implications from directions the user has explicitly chosen. When the user has expressed no choice, use conditional or candidate wording. Use existing Takeaways when needed to avoid misrepresenting an expressed decision.

For **Review / Improve**, evaluate the existing body against the framing, findings and their limits. Keep the user's expressed decisions visible. When a choice merits reconsideration, explain the consequential concern in the rationale and identify an alternative as an option for review. Improve wording and qualifications, or add material omitted implications. If the existing wording already fits, say so in the rationale and propose retaining it. A concern may point back to framing or analysis, but this action proposes no changes to either.

Use the rationale to explain the main basis or change, including any proposed reconsideration. The rationale is displayed separately from the body. Acceptance reflects the user's choice of wording and provides no independent corroboration. Follow the framework extension for methodological fit.
